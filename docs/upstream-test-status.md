## 功能差异清单

开发版的「任务 → 上游扩展」包含赛季活动快速战斗预览、领取活动奖励、领取通行证、浏览街机菜单、
救赎之塔快速战斗、装备单次精炼、末日之书挑战、亲密度谈心、关闭游戏、跑商库存盘点和每日跑商。跑商入口复用原任务和配置。邮件可选普通和商品邮箱，
通行证检查带红点的卡片和页签。救赎之塔可从主页选择恶魔城卡带，走到祭坛并进入塔。
它选择最高已确认通关的难度，核对钥匙余额和预留量，确认场数后提交并核对结算。
单次速刷上限默认 1 场，可设置为 1 到 10 场。启用批量速刷且最高已通关难度低于 Lv.10
时至少保留一把钥匙。已确认余额不超过预留量时正常结束，无法读出余额时停止并报告失败。
活动领奖检查带红点的卡片，并在确认活动身份后使用可用的「全部领取」或「全部获得」。
同一活动内按顺序处理蓝边手形的逐条领取按钮，确认上一条结束后才处理下一条。
「领取免费转盘」默认关闭。开启后须核对免费单转控件与当前参与次数，同一活动同日只提交一次，
参与次数确认增加 1 后才记为完成。
扩展任务按需执行，待真实游戏完整验收。
「赛季活动快速战斗预览」从已选的普通或挑战第 5、10、15 关开始。
它在两帧中核对关卡名称和按钮位置，打开确认弹窗供查看。
装备精炼从用户已选装备的精炼分数页开始，每次复核按钮和材料消耗后才记录并提交。
每日精炼次数上限默认 1，可设置为 1 到 10。上一次成功提示消失、精炼页恢复后才会继续，提交待核对时会拦截重复操作。
末日之书可从主页、游戏卡珍藏集、其箱庭或挑战
面板开始，使用当前阵容，确认结算后尝试返回主页。
亲密度谈心按服装名称选择当前可见且已拥有的服装，默认使用题库回答一次并核对次数变化。
启用「补齐Lv.20谈心记录」后，已达 Lv.20 的指定服装逐次核对记录并补至 15/15。
同一服装当天提交待核对时暂停谈心；默认单次模式也会跳过已确认记录。题库默认读取本工作树的
`.local-dev/upstream/YES-BD2/src/tasks/affinity/data/counseling.json`，也可设置「谈心题库路径」。
「自动选择服装」默认关闭。开启后从当前可见列表挑选题库覆盖的已拥有服装，核对详情后使用当日额度。
同时开启补齐记录时，优先处理可补齐的 Lv.20 服装。
「服装列表扫描页数上限」默认 1，可设为 1–10。指定服装或自动选择需要继续查找时，
从当前视口向下滚动。翻页后无新确认服装即结束这次查找。
跑商库存盘点使用已打开的出售弹窗和设置中的「盘点商品名称」。两帧标题与拥有数量一致才记录。
开启「盘点可见出售列表」后，在出售列表双帧核对食品的商品名、类别和持有量，批量保存已确认项。
「出售列表扫描页数上限」默认 1，可设为 1–10。启用多页时，从当前位置向下滚动，连续页面未确认新增商品时结束本次盘点。
同一盘点日的最新读数保存在 `configs/trade-inventory.sqlite3`。任务详情的「库存日报」可按盘点日查看商品、数量和北京时间。
日报有上一盘点日时显示对照日期和库存差值。两日均有记录的商品才计算差值。
钓鱼按用户指示移出本轮。

## 开发版验收

在 `test` 工作区运行 `.\.venv\Scripts\python.exe main_debug.py`，进入「任务 → 上游扩展」。当前工作区的配置、库存数据库和开发账本随目录独立保存。

游戏内重点核对通行证红点、活动奖励、救赎之塔钥匙、谈心次数和出售弹窗数量。关机和关闭游戏同时启用时，关机优先。库存列表回放覆盖低于 1080p 的画面和双帧数量不一致的情况。

Python 门禁为 `.\scripts\run_checks.ps1 -Mode Final`。Electron 界面运行 `npm --prefix desktop/ui test` 和 `npm --prefix desktop/ui run build`。
