# 每日及每周奖励

领取游戏“任务”页面的每日、每周奖励，以及赛季通行证中当前可领取的等级奖励和任务经验。
尚未完成的任务会保留，不会执行任务内容，也不会因为任务进度不足而报领取失败。

## 使用方法

1. 根据需要开启“领取每日奖励”“领取每周奖励”和“领取赛季通行证奖励”。
2. 从游戏主页或每日、每周任务页启动“每日及每周奖励”。
3. 程序检查所选任务页和各张赛季通行证的“全部获得”，领取后复查状态，再返回主页。指南通行证会跳过。

“一键完成日常”中可以开启“领取每日及每周奖励”，在其余日常结束后统一领奖。
同一天再次运行日常也会复查新增奖励；也可以随时单独运行本任务。

没有可领奖励时，确认后正常结束。页面识别失败、领取次数达到上限或未能返回主页时，
本次运行会显示失败，保留现场供检查。
